# 01 · 玩家体验与范围规格

## 启动路径

`首页 -> 新游戏/继续游戏/导入存档 -> (新游戏: 创建角色) -> 进入场景 -> 行动 -> 世界判定 -> 简短沉浸叙事 -> 下一行动`

**角色创建字段：** 姓名、年龄、性别、职业、所在地、身体状况、性格、擅长/不擅长、末日前重要物品、同伴、最重要的人、恐惧、愿望。允许自由填写；技能初值合理封顶，不能随意写满。

## 主界面（移动端优先，同时兼容桌面）

- **顶部**：世界第 N 天/时刻、所在地、天气；临近风险仅显示合理可感知状态。
- **主要区域**：1—3 段沉浸式叙事；分段出现而非铺满属性表。
- **快捷栏**：当前可感知的 2—6 条动态行动建议（非动作白名单）。
- **自由行动栏**：任意文字；支持系统键盘语音输入；专用 STT 待适配后再开放。
- **抽屉**：背包/装备、状态、已知地图、关系、近期事件、游戏设置、存读档。
- **反馈**：新物品、状态变化、事件后果用简短标签或可折叠日志呈现；不透露隐藏机制。

## 动态按钮示例

场景：废弃楼内，门外有声音。

可见按钮：`观察门缝`、`仔细倾听`、`寻找遮蔽物`、`查看背包`。

玩家仍然可以输入：`把湿毛巾塞进门缝，躲到衣柜后面听脚步声`。语义层应解析为可处理的子动作，遇到复杂链式动作先生成拟执行步骤并征求确认；实际未做出的动作不能提前写入世界。

## 文字输出格式

**默认**：场景叙事（原因-感官-不确定性-后果），紧接 1 行状态变化，动态建议按钮与自由输入。

**可展开**：时间、天气、详细状态、装备/背包、附近情况、事件日志。原始 24 节的冗长固定模板不作为每回合强制输出；数据仍完整保留。

## 游戏边界

- 不把游戏内容和真实世界任务混淆；角色行为只发生在虚构游戏世界。
- 允许正常失败、拒绝、资源匮乏；失败不能无端撤销世界既有事实。
- 稀有物资概率受地图类型、库存、搜刮历史影响。
- 死亡后提供回顾；复活/读旧档是存档选择，不是故事中无理由复活。

## 无网时的降级模式

可浏览存档、背包、日志和已生成内容；规则动作及基础模板叙事可继续（取决于已实现覆盖范围）。未配置语言模型时，不得宣称具有完整的自由语言理解和丰富动态 NPC 对话。

## 首个垂直切片（唯一验收样本）

废弃居民楼：
1. 角色在门内听见楼梯间的响动；
2. 点击 `透过门缝观察`；
3. 系统分别判定 `是否看见线索` 与 `是否暴露`；
4. 可继续搜索、躲避、与 NPC 接触；
5. 道具变化、时间推进和关系变更能存档并读回；
6. 重新加载后相同物品不能无故刷新、NPC 不失忆；
7. 玩家可自由输入超出按钮的举动，并接收合理处理或明确的约束反馈。
