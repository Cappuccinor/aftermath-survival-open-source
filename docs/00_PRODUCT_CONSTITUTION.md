# 00 · 产品宪章 / 不可漂移约束

## 唯一产品定位

《末日余生》= **沉浸式文字生存模拟器** + **轻量图形交互** + **自然语言自由行动** + **可靠世界存档**。

**本项目不是**传统固定选项小说、不是把场景完全搬成 3D 动作游戏、也不是 LLM 即兴写爽文。

## P0 不可妥协（任一不满足即不准宣布版本验收）

1. 玩家能提出菜单以外的合理行为；按钮不能成为行为白名单。
2. 没有无条件成功/失败：规则基于技能、对象、环境、耗时、风险和可复现随机数。
3. 事件前后自洽：物品/人物/地点同一 ID，不能凭叙事刷新。
4. AI 只能读取经过筛选的世界信息，用结构化意图提议，不能直接写存档或决定事件已发生。
5. 玩家可以长期保存和恢复**整个**世界；可导入/导出、多存档；存档失败不得宣称成功。
6. 不替玩家完成未授权的一串行为；长操作可发起后确认，中断条件必须可见。
7. NPC 有独立目标、记忆和相互矛盾的利益；不必始终帮助玩家。
8. 死亡与失败有过程和原因；不为了剧情无端拯救或杀害玩家。
9. 文字叙事构成主要体验；按钮、状态条和日志减轻输入和记忆负担，不用信息墙覆盖故事。
10. 游戏不泄露未被玩家合理感知的秘密、概率、坐标或 NPC 的内心状态。

## P1 体验原则

- 行动建议始终是**建议**：2—6 个按钮为宜，玩家始终可自由输入；数量是 UI 目标，不是动作上限。
- 自然语言输入、设备自带语音输入、未来可选的专用语音转文字适配器共用一个动作接口。
- “一键观察/搜索/休息”必须仍占用时间，并引发世界后果。
- 状态条可折叠、背包可查看；玩家不必每回合读一张冗长属性表。
- 叙事可配置简洁/标准/详细；默认短段落，不取消氛围。
- 场景插画、TTS、额外地图仅为可选插件，不承担裁决事实的职责。

## P0 风险控制

- **不作无限自由的承诺。** 系统支持开放语义输入，但执行只能落到已实现的动作原语或通用技能检查。超出能力要解释缺口/请求进一步明确，而不是假装完成。
- **离线世界与存档的冲突：** 离开后默认暂停；可选启动时按规则补算一段离线时间，需预览重大事件，不允许运行隐藏后台服务。
- **剧情文本与权威状态分离：** 文本遗漏细节不改变事实；文本说“找到了水”，必须先有物品转移事件。反之不得仅凭文案给玩家物品。

## 非目标（至少在 V1.0 前）

- 不建设 MMORPG、多玩家联网、公会战、真实经济市场。
- 不追求高精度 3D 角色/建筑/车辆动画。
- 不在每次行动后生成昂贵的全屏图片。
- 不自行训练基础大语言模型。
- 不把自由交互压缩成固定的 3—5 个剧情分支。

## 变更权限

本文件只允许用户明确要求下修改；Codex 可以提出 ADR，但不应自行改动 P0 清单。任何影响 P0 的提交，应暂停并寻求批准。
